## 🚀 Featured Projects

### Kotlin Multiplatform & Cross-Platform

#### [Aura](https://github.com/Helmy2/Aura)
Beautiful wallpaper & video discovery app built with Kotlin Multiplatform. Browse and download stunning wallpapers and videos from Pexels with native experiences on Android (Jetpack Compose) and iOS (SwiftUI). Features MVI architecture, infinite scroll, favorites system, and video playback.

#### [Mudawama](https://github.com/Helmy2/Mudawama)
A serene, offline-first Muslim habit tracker built with Kotlin Multiplatform. Features prayer tracking, Quran progress, Athkar & Tasbeeh counter, Qibla compass, and custom habits. Android uses Compose Multiplatform; iOS uses native SwiftUI backed by shared Kotlin domain/data logic.

#### [expense-tracker](https://github.com/Helmy2/expense-tracker)
A Kotlin Multiplatform expense tracker for Android and iOS. Built with Jetpack Compose (Android) and native SwiftUI (iOS). Features home dashboard, expense tracking, budget management, recurring transactions, and cross-tab sync with Clean Architecture.

#### [CrossCart](https://github.com/Helmy2/CrossCart)
A cross-platform (iOS, Android, Desktop) shopping app built with Kotlin Multiplatform and Jetpack Compose. Features offline caching with Room, real-time data synchronization, and a complete modern shopping experience.

#### [POS-ERP](https://github.com/Helmy2/POS-ERP)
A robust, offline-first Point of Sale (POS) and Enterprise Resource Planning (ERP) application built with Kotlin Multiplatform for Android and Desktop. Features Room + Supabase sync, role-based access control, and real-time updates.

#### [CleanEntry](https://github.com/Helmy2/CleanEntry)
A Kotlin Multiplatform case study for Android, iOS, and Desktop, built with Clean Architecture, MVI, Compose Multiplatform, and a hybrid SwiftUI approach. Serves as a comprehensive learning resource.

#### [hijri-date-picker](https://github.com/Helmy2/hijri-date-picker)
A production-ready KMP Hijri calendar picker supporting Android, iOS, and Desktop with platform-consistent behavior. Published to Maven Central with comprehensive documentation.
